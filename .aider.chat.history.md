### Resumo do Contexto do Projeto

O projeto parece ser uma assistente cognitiva local desenvolvida para funcionar em um ambiente Android. O sistema é composto por vários componentes, incluindo agentes, serviços, bancos de dados e APIs RESTful. Aqui estão os principais aspectos:

1. **Arquitetura Cognitiva**:
   - A arquitetura é baseada em uma camada de sensores que coletam eventos do sistema Android.
   - Esses eventos são processados por um pipeline de atenção, que filtra e enriquece os eventos antes de serem publicados no kernel cognitivo.

2. **Kernel Cognitivo**:
   - O Kernel é o coração do sistema, responsável por despachar eventos para agentes especializados.
   - Ele também mantém métricas básicas sobre a atividade do sistema.

3. **Agentes**:
   - Agentes como `AgenteInferencia`, `AgenteReflexo`, `AgenteNotificacoes` e outros são responsáveis por processar eventos de diferentes maneiras.
   - Por exemplo, o `AgenteInferencia` pode inferir padrões com base em eventos, enquanto o `AgenteReflexo` decide sobre eventos com base em regras simples.

4. **Serviços**:
   - Serviços como `ServicoLLM`, `MemoriaEpisodica`, `MemoriaPerfil` e outros fornecem funcionalidades específicas.
   - Por exemplo, o `ServicoLLM` é responsável por interagir com um modelo de linguagem para gerar respostas baseadas em eventos.

5. **Banco de Dados**:
   - O sistema utiliza bancos de dados SQLite para armazenar eventos episódicos e informações semânticas.
   - A `MemoriaEpisodica` é responsável por arquivar eventos imutáveis, enquanto a `MemoriaPerfil` mantém estatísticas sobre o comportamento do usuário.

6. **APIs RESTful**:
   - As APIs permitem que outros sistemas interajam com o assistente, permitindo receber e processar eventos externos.

### Objetivo Principal

O objetivo principal do projeto é criar uma assistente cognitiva local que possa aprender e responder de forma inteligente aos eventos ocorridos no sistema Android. O sistema deve ser capaz de inferir padrões, tomar decisões com base em regras simples e interagir com o usuário através de notificações.

#### Onde devo injetar a lógica de prioridades para não sobrecarregar o motor de atenção?  

Para injetar a lógica de prioridades e evitar sobrecarregar o motor de atenção, você pode seguir os seguintes passos:

1. **Criar um novo agente de prioridade**: Este agente será responsável por classificar eventos com base em suas prioridades.
2. **Integrar o novo agente no pipeline de eventos**.

### Passo 1: Criar um novo agente de prioridade

Vamos criar um novo arquivo `agentes/agente_prioridade.py` e adicionar a lógica para classificar os eventos com base em suas prioridades.

#### agentes\agente_prioridade.py
```python
"""
agentes/agente_prioridade.py

Agente responsável por classificar eventos com base em suas prioridades.
"""

from core.evento import EventoCanonico
from core.tipos import PrioridadeEvento
from core.kernel import kernel

class AgentePrioridade:
    def __init__(self):
        pass

    async def processar(self, evento: EventoCanonico):
        # Implemente a lógica para classificar a prioridade do evento
        if evento.categoria == "MEDIA":
            evento.prioridade = PrioridadeEvento.ALTA
        elif evento.categoria == "APP_FOREGROUND":
            evento.prioridade = PrioridadeEvento.MEDIO
        else:
            evento.prioridade = PrioridadeEvento.BAIXO

        # Publica o evento com a prioridade atualizada
        await kernel.publicar(evento)

# Registre o agente de prioridade no Kernel
kernel.registrar(
    filtro=lambda e: True,  # Este agente deve receber todos os eventos
    callback=AgentePrioridade().processar
)
```

### Passo 2: Integrar o novo agente no pipeline de eventos

Agora, precisamos garantir que o evento seja publicado apenas após a classificação de prioridade. Isso pode ser feito ajustando a ordem dos agentes registrados no `main.py`.

#### main.py
```python
# main.py
import asyncio
from fastapi import FastAPI
from contextlib import asynccontextmanager
from fastapi.middleware.cors import CORSMiddleware
import uuid
from core.evento import EventoCanonico


from core.kernel import kernel
from core.tipos import CategoriaEvento, TipoAcao, OrigemEvento
from agentes.agente_perfil import AgentePerfil
from agentes.agente_inferencia import AgenteInferencia
from agentes.agente_decisao import AgenteReflexo
from agentes.agente_notificacoes import AgenteNotificacoes
from agentes.agente_roteador_cognitivo import AgenteRoteadorCognitivo
from agentes.agente_episodico import AgenteEpisodico
from agentes.agente_raciocinio import AgenteRaciocinio
from agentes.agente_prioridade import AgentePrioridade  # Importe o novo agente
from api.eventos import router as eventos_router
from api.websocket import router as ws_router
from banco.database import inicializar_banco
from servicos.memoria_episodica import MemoriaEpisodica


# ==========================================
# 1. GERENCIADOR DE CICLO DE VIDA (BOOT)
# ==========================================
@asynccontextmanager
async def lifespan(app: FastAPI):
    print("[Kernel] Verificando e inicializando estruturas de memória (SQLite)...")
    await inicializar_banco()
    print("[Kernel] Estruturas neurais prontas!")

    # Inicia o KERNEL de forma assíncrona
    asyncio.create_task(kernel.iniciar())
    print("🚀 Kernel Cognitivo iniciado.")

    yield  # A API fica rodando neste ponto

    print("[Kernel] Desligando sistema cognitivo...")
    from banco.database import async_engine

    await async_engine.dispose()


# ==========================================
# 2. CRIAÇÃO ÚNICA DO CÉREBRO (APP)
# ==========================================
app = FastAPI(lifespan=lifespan)

# ==========================================
# 3. MIDDLEWARES E SEGURANÇA
# ==========================================
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

# ==========================================
# 4. MAPEAMENTO DE SENSORES E SAÍDAS (ROTAS)
# ==========================================
app.include_router(eventos_router)
app.include_router(ws_router)

# ==========================================
# 5. INSTANCIAÇÃO E REGISTRO DOS AGENTES
# ==========================================

agente_perfil = AgentePerfil()
agente_inferencia = AgenteInferencia()
agente_reflexo = AgenteReflexo()
agente_notificacoes = AgenteNotificacoes()
agente_roteador_cognitivo = AgenteRoteadorCognitivo()
agente_episodico = AgenteEpisodico()
agente_raciocinio = AgenteRaciocinio()
agente_prioridade = AgentePrioridade()  # Instancie o novo agente

# Registre os agentes no Kernel
kernel.registrar(
    filtro=lambda e: e.acao == TipoAcao.INTENCAO_INTERACAO,
    callback=AgenteRaciocinio().processar
)

kernel.registrar(
    filtro=lambda e: e.acao == TipoAcao.EVENTO_COMPLEXO,
    callback=agente_roteador_cognitivo.processar
)

kernel.registrar(
    filtro=lambda e: e.acao == TipoAcao.INTENCAO_INTERACAO or e.acao == TipoAcao.EVENTO_COMPLEXO,
    callback=AgenteNotificacoes().processar
)

kernel.registrar(
    filtro=lambda e: e.acao == TipoAcao.INTENCAO_INTERACAO or e.acao == TipoAcao.EVENTO_COMPLEXO,
    callback=agente_episodico.processar
)

# Registre o novo agente de prioridade no início do pipeline
kernel.registrar(
    filtro=lambda e: True,  # Este agente deve receber todos os eventos
    callback=AgentePrioridade().processar
)

kernel.registrar(
    filtro=lambda e: e.acao == TipoAcao.INTENCAO_INTERACAO or e.acao == TipoAcao.EVENTO_COMPLEXO,
    callback=agente_inferencia.processar
)

kernel.registrar(
    filtro=lambda e: e.acao == TipoAcao.INTENCAO_INTERACAO or e.acao == TipoAcao.EVENTO_COMPLEXO,
    callback=agente_reflexo.processar
)
```

### Explicação

1. **Novo Agente de Prioridade**: O `AgentePrioridade` é responsável por classificar os eventos com base em suas prioridades.
2. **Integração no Pipeline**: O novo agente é registrado primeiro, garantindo que todos os eventos recebam a classificação de prioridade antes de prosseguir para os outros agentes.

Com essas alterações, o sistema terá uma lógica adicional para classificar as prioridades dos eventos, ajudando a evitar sobrecarregar o motor de atenção.
